# Priya & Umesh (Muskan & Ankush) — Wedding Invitation

Full clone of [priya-umesh.lovable.app](https://priya-umesh.lovable.app).

## 🌟 Included Sections & Features
- **Royal Intro Screen** with Lord Ganesha idol, wax-sealed envelope, and falling daisy/rose petals
- **Auspicious Background Shehnai / Music** (`wedding-song.mp3`) with floating music toggle button
- **Shri Ganesh & Shiva-Parvati blessings**
- **Save The Date Scratch Card** (reveal date: Friday, 20 November 2026)
- **Wedding Events Timeline** with custom background artwork:
  - Chota Ban
  - Bheru Pujan
  - Bandoli
  - Vinayak Sthapana
  - Kalash
  - Haldi
  - Mahila Sangeet
  - Ring Ceremony
  - Baraat Swagat
  - Reception
  - Shubh Vivah (Pheras)
- **Venue & Google Maps / QR Scanner** (Aashika Resort, Bhilwara)
- **Family Details & Welcome**

## 🚀 How to Run Locally

### Option 1: Node.js (Recommended)
```bash
npm start
# or
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Option 2: Python
```bash
python server.py
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
